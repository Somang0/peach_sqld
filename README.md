## 🚀 Why this project?

SQLD 공부를 하다 보면 개념을 읽을 때는 이해한 것 같지만, 문제로 만나면 헷갈리는 순간이 많습니다.

그래서 이 프로젝트는 거창한 LMS보다 **“오늘 문제 몇 개 풀고, 어디서 틀렸는지 바로 확인하는 흐름”**에 집중했습니다.

별도의 서버나 데이터베이스 없이 동작하며, GitHub Pages에 그대로 올려 사용할 수 있습니다.


- 세션 전체 삭제
- JSON 백업

을 제공합니다.

### 🎲 Random Quiz Builder

랜덤 문제풀이를 고정 10/20문제 버튼에서 한 단계 확장했습니다.

```text
출제 범위 선택
→ 전체 / 데이터 모델링 / 데이터 모델과 SQL / SQL 기본 / SQL 활용 / 관리 구문

문제 수 선택
→ 10 / 20 / 30 / 50 / 100

보기 순서 랜덤
→ ON / OFF
```

보기 순서를 섞어도 정답 인덱스가 함께 다시 계산되므로 채점과 해설은 그대로 유지됩니다.

문제 수가 해당 과목의 전체 문제 수보다 많으면 그 과목에서 가능한 문제를 전부 출제합니다.

### 📦 Question Bank

`TalkFile_quiz.txt`의 문제 본문과 `TalkFile_ans.txt`의 정답·해설을 `id` 기준으로 결합해 문제은행을 구성했습니다.

- 총 600문제
- 전 문제 4지선다
- 정답 키 포함
- 문제별 해설 포함
- SQL 코드 블록 표시
- SVG 도식 문제 표시
- Markdown 형식 데이터 표를 반응형 HTML 테이블로 표시

## 💾 Study Data

현재 버전은 브라우저의 `localStorage`를 사용합니다.

```text
sqldState
├─ 누적 풀이 수
├─ 누적 정답 수
├─ 오답 문제 ID
└─ 북마크

sqldStudySessions
└─ 세션별 공부기록
```

같은 브라우저에서는 새로고침하거나 다시 접속해도 기록이 남습니다.

단, 브라우저 데이터를 지우거나 다른 기기로 이동하면 자동 동기화되지 않습니다. 그래서 공부기록 화면에 **JSON 내보내기** 기능을 넣었습니다.

장기적으로는 Supabase/Firebase를 붙여 로그인 기반 동기화로 확장할 수 있습니다.

## ➕ Add Your Own Question

```js
{
  id: 101,
  category: "SQL 활용",
  tag: "JOIN",
  question: "LEFT JOIN에 대한 설명으로 알맞은 것은?",
  choices: ["보기 1", "보기 2", "보기 3", "보기 4"],
  answer: 1,
  explanation: "정답 해설"
}
```

`answer`는 0부터 시작합니다.

```text
0 → 1번
1 → 2번
2 → 3번
3 → 4번
```

## v11 오류 수정

- 손상된 `localStorage` JSON 때문에 사이트 전체가 멈추는 경우 자동 복구
- 빈 문제 범위가 선택됐을 때 `undefined` 문제로 크래시하지 않고 안내 메시지 표시
- Markdown 구분선이 없는 `학번 | 국어 | 영어 | 수학` 형태의 표도 자동으로 HTML 표로 렌더링
- SVG 내부 링크 속성을 제거해 문제 도식 렌더링을 더 안전하게 처리
- 오답 횟수 배지가 현재 문제에서 즉시 갱신되도록 수정
- 이전 문제 이동 시 문제 카드 위치로 자연스럽게 스크롤되도록 보정

> v11의 로고 이미지는 v10과 동일합니다. 투명 배경 PNG 교체 시 `assets/sqld-peach.png`와 `assets/favicon.png`만 바꾸면 됩니다.


## v12 실전 모의고사 · SQL · 모바일 개선

- 실전 모의고사는 선택 즉시 정답/해설을 공개하지 않고 답안만 저장
- 실전 모의고사에 `모의고사 제출하기` 버튼 추가, 90분 종료 시 자동 제출
- 제출 전에는 답안 변경 가능, 제출 후 정답/오답 및 해설을 일괄 채점
- 결과 화면에서 `제출 답안 검토`로 50문제 정답/해설 확인 가능
- 미응답 문제는 제출 시 오답 처리
- SQL은 한 쌍 백틱(\`SELECT ...\`), 두 쌍 백틱(\`\`SELECT ...\`\`), `sql` 코드펜스를 모두 코드 블록으로 렌더링
- SQL 주요 키워드 강조 및 모바일 코드 가독성 개선
- 모바일 문제 네비게이터를 기본 접힘형으로 변경하고 5열 번호판으로 정렬
- 모바일 문제풀이 헤더/선택지/표/버튼 간격을 재정렬해 가독성 개선
